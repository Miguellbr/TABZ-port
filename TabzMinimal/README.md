# TabzMinimal

Unity 2022.3.62f1 project generated by `.github/workflows/build-tabzminimal.yml`. Do not edit it by hand: the branch
`tabz-minimal` is overwritten on every run.

What it contains

- `Assets/Plugins/Managed`: the ORIGINAL DLLs. `Assembly-CSharp.dll` has its `UnityEngine.Input` calls redirected to
  `TabzInputShim`; `Assembly-CSharp-firstpass.dll` has the Steam (and, for this first build, FMOD) native calls stubbed.
- `Assets/Resources`: every original prefab, with its original components. Script references were re-pointed from the
  AssetRipper scripts to the classes inside the DLLs. Nothing was deleted. See `RECOVERY-REPORT.md`.
- `Assets/Scenes/TabzMinimal.unity`: original root objects (ServiceLocator, SoundStuff) carried over from TABZ_World.
- `Assets/TabzBoot`: boot code (flat Terrain, runtime NavMesh, Photon offline, spawn of the original prefabs), on-screen
  touch controls that answer the original scripts' Input calls, and an in-game log with a copy button.
- `ProjectSettings`: the original physics, tag/layer and time settings.

Build Automation (suggested, to be confirmed by the owner): branch `tabz-minimal`, subfolder `TabzMinimal`,
Unity 2022.3.62f1, Android ARMv7. The editor script `TabzMinimalBuild.BuildAndroid` can be used as build method.

Not verified: none of this has run on a device yet.
